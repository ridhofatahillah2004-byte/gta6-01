SOLMAR: Streets of Vista Mar — an open-world crime game in the browser. Steal cars, outrun the VCPD as the wanted heat rises, and run four jobs for fixer Mara Voss across a sun-soaked coastal city with traffic, pedestrians, a beach and pier, a skyline, a casino, a stadium and a lighthouse. Play on foot or behind the wheel, hunt the 12 hidden cash stashes, and save your progress to localStorage. No build step, no network: every asset is generated in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD moves and drives, drag the mouse to orbit the camera, click to shoot, E steals or exits a car, 1–4 start a mission, P pauses, M mutes.
